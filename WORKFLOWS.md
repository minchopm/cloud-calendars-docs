# Cloud Calendars: Sync & Widget — practical workflows

These are suggested user procedures, not claims that automated tests have been performed. Each workflow has a concrete outcome to inspect.

## Compare work and personal availability

Show the relevant sources side by side and confirm none is filtered out. Inspect the full day before proposing a meeting time. Check time-zone differences with the other participant rather than relying only on the displayed local hour.

## Move a recurring event

Confirm the calendar is editable. When moving an occurrence, check whether the operation affects one event or the series. Verify the result in the source account and confirm participant notifications where applicable.

## Plan an outdoor appointment

Select the correct place and forecast date, then compare the event time with available hourly weather. Treat weather as a forecast that can change. Refresh the app near the appointment; a website demonstration or an old widget is not a live guarantee.
